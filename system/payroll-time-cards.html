Layer 01 — The System · Accounting

Payroll & Time Cards

How everyone submits time, and how Accounting runs the full payroll cycle — collect, audit, process, build & file, post — in one guided flow.

Home → The System → Payroll & Time Cards
For everyone
Submitting your time

Every hour you work is billed to a project (or a company/overhead), so your time flows to the right place and the companies settle up correctly. A complete time card needs six things — most fill in for you:

  • You (the submitter) · hours · date · project or customer — you provide these.
  • Cost code and pay period — filled automatically from your employee record and the calendar.

Pick the pay period from the list (it's required) so your time never lands in the wrong one — the old month-vs-period mismatch is gone.

The fast way
Just tell Kompass

You don't have to fill out a form. Open Kompass (the sparkle button, every page) and say how you spent your time:

“Log 5 hours today split evenly across Lot 17B, 18B, and 19B at Cold Stream.”

Kompass creates a proper time card for each project with the right cost code and pay period. If it can't match a project by name, it asks rather than guessing — so your time is never misfiled. You can talk, type, or snap a photo of handwritten hours.

For Accounting
Run Payroll — the five phases

Pick an entity and a pay period, then work down the phases. Each shows its status and gates the next.

1 · Collect
Gather time cards
Saved views per entity. Select all and Mark received in one click; export the CSV. No more checking off rows one at a time.
2 · Audit (QC)
Quality control
Flags who hasn't submitted, out-of-period dates, and projects with no Intacct code. Shows a submission dashboard; Kompass can draft reminder emails to stragglers (drafts only — you review and send).
3 · Process
Group & allocate
Groups each person's hours by project and computes % time × gross × (1 + tax rate) = billed — the intercompany allocation, done for you.
4 · Build & file
The workbook
Produces the two-tab Journal Entry + Allocations workbook and files it to the entity's payroll log. Upload the NV Payroll PDF so Kompass reconciles the JE bank lines to the register.
5 · Post to Intacct
Manual, for now
The output is Intacct-ready; key it in and mark posted. (Automatic import is a later phase.)
Behind the scenes
Config & the payroll log

The config is editable in S-BOS — the four entities (Stitser BUILT, BUILT./KCS, Realm, The Eddy), their rosters, and the lookup maps (project → Intacct code, department, cost code → GL). When a new project appears, add its code once and every future period knows it. Kompass can add a code for you.

Every run is filed forever. Each period's workbook lands in the entity's payroll log — a permanent, time-stamped history, the same way project health reports are filed. Nothing lives only in someone's downloads folder.
