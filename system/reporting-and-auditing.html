Tool Guide — The System

Reporting & Auditing

One tool for every report and audit — project health, brokerage compliance, loan servicing — run on any record, reviewed with Kompass, and filed to a timeline you can track over time.

Home → The System → Reporting & Auditing
The Intention
What it is

Reporting & Auditing is a single tool that lives on the record it describes — a project or a loan today, with departments and companies to follow. It answers one question for that record over and over: how are we doing, and is everything in order?

Before this tool, that answer was scattered across three disconnected places — a project-health rating that only ever showed the latest week, a brokerage document audit that never filed a report, and a loan audit that produced a document but kept no history. They did the same thing conceptually — run an assessment against a record, produce a verdict and a list of findings, at a point in time — so they were merged into one.

The point of the tool is continuity and accountability: every report is filed as a document and kept in a timeline for that record. You can see how an element — say, a project's health — is trending, open any past report to read exactly what it said, and see who ran it and where it stands. Nothing evaporates in a chat window.

What It Produces
The report types

Each record offers the report types that make sense for it. When you click Run new report, only the applicable types appear.

Project Health Report
Projects · Green / Yellow / Red
Kompass reads the project's live signals — open and overdue tasks, pay-app cadence, budget vs. actuals, change orders, and how recently the record was touched — and assigns a GYR rating with a plain-English headline, summary, risks, and recommended actions. This is the report the leadership team reviews weekly.
Broker Compliance Audit
Projects · Clean / Minor / Material
Walks the deal's Google Drive Submittals folder, matches each file to the required-document checklist, and produces a clean action list of what is still missing. On finalize it links the matched files to their tasks (set to "Needs Agent Review") so the compliance file assembles itself.
Loan Servicing Audit
Loans · Clean / Minor / Material
An interactive review of one loan — terms, the interest math on the ledger, proof documents, compliance phases, and the payment schedule. Where Kompass finds the right value it proposes a concrete fix you can apply in one click; anything left open becomes a follow-up task on finalize.
How It Works

Timeline

1 · Run. Pick a report type. Kompass gathers everything it needs from the record and produces a draft — a verdict, a summary, and a list of findings. Nothing is committed yet.

2 · Review & chat (human in the loop). The report opens in a side panel. For the LLM-driven reports you can push back, clarify, or fill a gap in conversation — "the note says maturity is 1/1/2029," "this document is on file, here's the link" — and Kompass revises the findings. This is where your judgment shapes the result before anything is recorded.

3 · Finalize & file. When it's right, finalize. The full report is saved as a versioned document on the record, and its findings are put to work: on a loan, open items become assigned follow-up tasks; on a compliance audit, matched documents are linked to their checklist items. Applied loan fixes are written straight to the loan.

4 · Timeline. The finished report takes its place in the record's history, grouped with others of its type.

Two Ways to Run
On demand, or on a routine
Manual
You run it, you complete it
Open the tool on a record, click Run new report, review the findings, chat to refine, and finalize. Use this any time you want a fresh read — before a close, after a document drop, when a loan looks off.
Automated
A routine runs it for you
A routine can run a report on a schedule (the weekly project-health sweep already does) or ahead of a deadline, and file it automatically. Automated reports still land in the same timeline — and you can open one afterward to chat with it and adjust.
Seeing It Over Time
The timeline, trends & accountability

The tool's home view is a history log grouped by report type. Each group shows a row of verdict dots oldest-to-newest — a trend at a glance (improving, flat, or worsening vs. the prior run) — and every dot is clickable: open it to read the full narrative, findings, and the conversation behind it. This is what the old health rating never let you do.

Every row also shows who ran the report and where it stands (draft or filed). Because that's captured on every report, you can review a person's or a team's reports over time and evaluate follow-through objectively — not on impression, but on the record.

Verdicts use two simple scales so trends read cleanly: Green / Yellow / Red for health, and Clean / Minor / Material for audits. Both run best-to-worst, so an arrow can tell you the direction at a glance regardless of report type.

Where the Work Goes
Reports become documents, findings become work
A filed document
Versioned, on the record
Finalizing files the report into the record's documents as a dated, versioned file — so it's part of the permanent record, not just a screen you looked at once.
Follow-up tasks
Loan audits
Open findings on a loan audit open as assigned tasks (to the loan servicer) with a due date, so nothing found in the review falls through.
Linked documents
Compliance audits
Matched Drive files are linked to their checklist items and flagged for agent review — the compliance file builds itself as the audit runs.
Quick Start
How to use it

1. Open a project or a loan and go to the Reporting & Auditing tab (under Overview on a project).

2. Read the timeline — each group is a report type, each dot a past report. Click any to review it.

3. Click Run new report and pick a type to run a fresh one.

4. In the side panel, review the verdict and findings. For loan and health reports, chat to correct or add context; apply any proposed loan fixes.

5. Click Finalize & file. The report is saved to the record, findings become tasks or document links, and the new entry joins the timeline.

Note: report types that read Google Drive (compliance) need Drive connected; a report will tell you plainly if a connection is missing rather than fail silently.
