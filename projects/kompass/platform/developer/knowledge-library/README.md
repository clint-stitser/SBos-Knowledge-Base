## Entry Format

Each knowledge library entry uses this structure:

```markdown
# [Concept Name]

## What It Is
Plain-language definition.

## Why It Matters
Operational implication for a developer.

## Key Decision Points
Where this concept affects a go/no-go or action.

## Common Mistakes
What operators get wrong about this.

## Related Concepts
Linked entries.

## Tools and Resources
Forms, checklists, external references.
```
