# Developer Kompass — Decision Matrices

*Stub — to be built out in a dedicated session.*

## Decision Types

### 1. Deal Go/No-Go
**Question:** Should we pursue this deal?

**Criteria to define:**
- Minimum unlevered IRR threshold
- Maximum equity exposure
- Market / jurisdiction requirements
- Partner / capital requirements
- Timeline fit
- Risk tolerance filters

---

### 2. Partner Selection
**Question:** Should we bring in this partner / JV?

**Criteria to define:**
- Track record requirements
- Capital commitment minimums
- Control provisions
- Reference requirements

---

### 3. Lender Selection
**Question:** Which lender / which loan structure?

**Criteria to define:**
- Rate and fee tolerance
- Recourse vs. non-recourse preference
- Construction draw process requirements
- Relationship weight

---

### 4. Exit Criteria
**Question:** Sell, refi, or hold?

**Criteria to define:**
- Return threshold to trigger sale
- Market condition triggers
- Hold period preferences by asset class
