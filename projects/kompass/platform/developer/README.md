# Developer Kompass

**Who:** Principals running land development, LIHTC, infill, or value-add projects

**Job:** Manage the full development lifecycle — from acquisition through entitlement, construction, and disposition — with an LLM that understands deal structure, capital stacks, and regulatory context.

## Brain Categories

- Entities (legal and investment vehicles)
- Projects (by deal type and phase)
- Capital structure (debt, equity, gap financing)
- Entitlement status (phase, jurisdiction, approvals)
- Vendor performance (civil, legal, lender, broker, GC)
- Deal decisions (go/no-go history and rationale)
- Investor and partner profiles
- Knowledge library (SFR dev, LIHTC, multifamily, entitlement law)
