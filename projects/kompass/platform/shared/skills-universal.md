# Universal Skills — Shared Across All Kompass Products

These skills are available in every Kompass product. Domain-specific skills are documented in each product folder.

## Programmatic Skills (LLM-executed)

| Skill | Description |
|---|---|
| Quick Capture | Classify and file any input — text, voice, link — to the correct Brain location instantly |
| Email Triage | Sweep inbox, classify threads, draft replies, create tasks for actionable items |
| Buffer Session | Structured clearing session across all open tasks, decisions, and flagged items |
| Horizon Scan | Daily awareness scan of active projects, open tasks, and pending decisions |
| Decision Logger | Capture any decision with rationale, options considered, and outcome tracking |
| People Profile Builder | Structured intake for a new team member or counterparty profile |
| Vendor Rating Capture | Post-job rating entry for a subcontractor or vendor |

## Protocol Tools (Human-executed with LLM coaching)

| Tool | Description |
|---|---|
| Decision Matrix Review | Walk the go/no-go criteria for any decision type with LLM surfacing the right matrix |
| Onboarding Protocol | Step-by-step guide for introducing a new team member to Kompass |

## Routines (Scheduled, autonomous)

| Routine | Schedule | Description |
|---|---|---|
| Daily Horizon Scan | Daily @ 7am | Surfaces what's alive and needs attention today |
| Weekly GYR Summary | Monday @ 8am | Project health across all actives |
| Email Triage | Daily | Classifies inbox and drafts replies for approval |
| Decision Log Review | Friday | Surfaces open decisions and patterns over the last 30 days |
