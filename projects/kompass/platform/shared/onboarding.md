# Onboarding — The First Five Minutes Standard

Every Kompass product must produce a tangible result in the first five minutes. This is the non-negotiable onboarding standard.

## The Standard

By the end of the first five minutes, the operator must have:
1. At least one project or record in the Brain
2. At least one counterparty or team profile seeded
3. At least one routine running
4. A visible Brain Setup Score with clear next steps

## Developer Kompass
1. Name your first active project
2. Tell Kompass the deal type, location, and current phase
3. Add one key counterparty (partner, lender, or broker)
4. Run the Horizon Scan
5. Set up the Daily Horizon Scan routine

## Contractor Kompass
1. Name your first active job
2. Tell Kompass the contract amount and current phase
3. Add your primary owner or GC contact
4. Capture your first open invoice or pay app item
5. Set up the Weekly Job Cost Flash routine

## Agent Kompass
1. Name your first active listing or buyer client
2. Describe the client — what they're looking for, timeline, motivation
3. Capture the next action required for that client
4. Set up the Daily Horizon Scan routine
5. Run an email triage sweep

## Personal Kompass
1. Name your three most important areas of life right now
2. Tell Kompass your #1 priority for this week
3. Log your current health baseline
4. Run the Morning Ritual
5. Set up the Daily Horizon Scan routine

## Brain Setup Score Dimensions

- Entity and project data completeness
- People profiles (team + key counterparties)
- Vendor ratings (% of active vendors rated)
- Decision matrices (% of recurring decision types configured)
- Knowledge library (% of domain areas seeded)
- Integration connections (Gmail, Drive, Smartsheet, QuickBooks)
