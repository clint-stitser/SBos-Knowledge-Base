# The Feed — The Assistant's Outbox

## What It Is

The Feed is where every completed task, routine, and proactive insight surfaces as a card. It is the assistant's outbox — what it did while the operator was busy.

## Card Types

| Card Type | Description |
|---|---|
| Routine results | Morning horizon scan, weekly GYR summary, scheduled reports |
| Action drafts | Emails, pay app documents, decision memos ready for approval |
| Flags | GYR status changes, expiring deadlines, missing documents |
| Decisions pending | Items needing a go/no-go call before the assistant can proceed |

## Human-in-the-Loop

Human approval is required for all external actions. The assistant drafts; the operator approves. Nothing ships without a tap.

- Approve → action executes
- Edit → operator modifies draft, then approves
- Skip → card dismissed, no action taken
- Defer → card snoozed to a specified time

## Full Run History

Every card retains its full context — inputs, outputs, and the conversation behind it. Audit trail preserved indefinitely.
