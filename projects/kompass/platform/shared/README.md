# Shared Architecture

All four Kompass products share the same underlying architecture. This folder documents the components that are common across Developer, Contractor, Agent, and Personal Kompass.

## Files

| File | Description |
|---|---|
| `brain-model.md` | The Brain: domain-structured memory, hierarchy, how it grows |
| `intelligence-stores.md` | The six intelligence stores (people profiles, vendor ratings, decision matrices, decision log, knowledge library, project data) |
| `operator-assistant.md` | Kompass: the AI operator assistant, context triggers, what makes it different |
| `feed-model.md` | The Feed: the assistant's outbox, card types, human-in-the-loop |
| `skills-universal.md` | Skills shared across all four products |
| `routines-universal.md` | Routines shared across all four products |
| `onboarding.md` | Onboarding flow, Brain Setup Score, first five minutes standard |
| `ux-principles.md` | User experience principles governing all Kompass products |
