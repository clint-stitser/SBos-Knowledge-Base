# Agent Kompass

**Who:** Real estate brokers and agents managing a pipeline of listings, buyer clients, and referral relationships

**Job:** Stay on top of active transactions, manage disclosure compliance, track client relationships, and generate business from existing relationships.

## Brain Categories

- Client profiles (buyer / seller, 7-section model)
- Listing pipeline (status, showing activity, price history)
- Transaction status (phase, pending items, closing date)
- Disclosure checklist (by transaction)
- Commission structure (by transaction, splits, referrals)
- Referral network (source tracking, reciprocal relationships)
- Knowledge library (CAR/NAR forms, 1031, disclosure requirements)
