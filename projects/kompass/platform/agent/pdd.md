# Agent Kompass — Product Design Document

*Stub — to be built out. See `platform-pdd.md` for shared architecture.*

## Target User

Real estate brokers and agents managing a pipeline of listings, buyer clients, and referral relationships.

## Unique Brain Structure

- Client profiles (buyer vs. seller, motivation, timeline, financial position)
- Listing records (property details, pricing history, showing activity, offers)
- Transaction pipeline (phase, contingencies, closing timeline)
- Referral network (source, reciprocal relationships, volume)

## Domain-Specific Decision Matrices

- Listing go/no-go (pricing alignment, seller motivation, exclusivity terms)
- Offer acceptance criteria (client-specific thresholds)
- Client acceptance criteria (motivation fit, timeline fit, financing status)

## Domain-Specific Skills

- Listing Pipeline Manager
- Disclosure Compliance Audit
- Client Relationship Tracker
- 1031 / DST Education Flow
- Commission Tracker

## Knowledge Library Domains

- Disclosure requirements (Nevada-specific, CAR/NAR forms)
- 1031 Exchange and DST education (for disposition client conversations)
- Offer and negotiation mechanics
- Commission structures, splits, and referral fee rules
- Listing agreement fundamentals
- Market analysis and pricing methodology
