# Platform Fundamentals — the foundational course

**Purpose:** the ordered path every new user (team member, operator, or licensee) walks to *actually grasp* how S-BOS works before using it. These are the "you can't skip these" articles — the mental model, not the reference shelf. Complete them in order.

> **How this is grouped:** each lesson below is a Knowledge Base article tagged `course: platform-fundamentals` with an `order`. Domain-reference articles (jurisdiction codes, financing guides, CrossMod law) and internal build docs (Build Decisions Log, Dispatch Architecture, Self-Hosted Build Loop) are intentionally **not** in this course — they're the reference shelf and the engine room, consulted as needed, not prerequisites to understanding.

## The path

1. **Welcome to S-BOS** — what this is and why it exists (the vision: one operating system for the business *and* the life around it; Kompass as the assistant that clears the fog).
2. **The Game System — Situations, Phases, Pillars & the Score** — *the core mental model.* Who's-playing / what's-the-score / how-much-time; lifecycle vs. ongoing situations; the two axes (Progress = Phases+Gates, Health = Pillars); fractal across project/asset/division/company; GYR; commitment. **If you read only one, read this.**
3. **Strategic Framework (reference)** — the precise definitions and data model behind Course 2: Pillar/Goal/Phase/Task ladder, the Stats-fed score, 4-level GYR, the commitment lock. The lookup companion to the teaching article.
4. **Projects: Lifecycle, Gates, Stages & Posture** — how *lifecycle-mode* work moves: the G0–G5 gates, what qualifies a project to advance, and posture/portfolio bands.
5. **Project Hierarchy & Subdivision** — how work nests (asset → building → unit; parent/child projects) so roll-ups and scope make sense.
6. **Multi-Entity Tenancy & Relationship Access** — how companies/entities, departments, and partner/customer access work — the scope model and why the vernacular adapts to who's looking.
7. **The Actuals Loop & the Score** — where the numbers come from: Stats (feeds + routine capture), time cards, budget-vs-actual — the plumbing behind "what's the score."
8. **Asset Management Blueprint** — a full worked example of an *ongoing* game: the 7 Key Situations, recurring-cycle projects, covenants/thresholds, and how it activates onto a real asset (Cal Ave). Ties every prior lesson together.

## After the fundamentals
Once these land, a user is ready for role-specific paths (an asset manager, a PM, a division lead) and the reference shelf. The fundamentals are the shared language; everything else is applied.
